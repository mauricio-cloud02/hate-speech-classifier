# Artifacts Directory

This folder stores trained model artifacts generated by running the training script.

Generate artifacts with:

```bash
python3 -m src.train --data_path data/labeled_data.csv --output_dir artifacts
```

Typical output files include:

- `artifacts/baseline.joblib`
- `artifacts/nb.joblib`
- `artifacts/svm.joblib`

These `.joblib` model artifacts are generated files and should not be committed to the repository.
